 Use Case Description

Use Case Name:Pick Up Parcel( ID:UC-01 Importance Level:High

)

Primary Actor: Recipient ()  Use Case Type:Detail, Essential

Stakeholders and Interests:
 (Recipient) Wants to receive prompt arrival notifications; safely collect
parcels in person via physical ID verification; authorize a recipient's representative online when unavailable;
and receive a confirmation email upon pickup to ensure package security. (



 )

 (Recipient's Representative) Wants to pick up parcels smoothly using only a physical ID per
authorization, without complex paperwork, while ensuring personal photos are used
strictly for auditing. (

)

 (Administrator) Wants to look up pending parcels quickly via 4-digit codes,
verify visitors' IDs accurately, eliminate paperwork through photo proof, reduce manual
errors, and maintain complete audit trails for disputes. ( 4 



)

Brief Description:

This use case specifies the parcel pickup procedure at the management office. The

generalized actor Resident specializes into Recipient (in-person pickup) or Recipient's Representative (proxy
pickup). Upon arrival, the system notifies the recipient, who can authorize a recipient's representative online
if needed. Onsite, the Concierge enters the 4-digit code on the desktop system to query
details, verifies the visitor's ID according to the assigned role, captures an onsite handover
photo, updates the parcel status to "Picked Up", logs the audit record, and dispatches a
pickup notification email to the recipient.
